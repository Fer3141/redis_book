# El pequeño libro de Redis

Una guía breve y práctica para entender Redis desde cero, escrita en español.

Este libro está dividido en capítulos para leerlo en orden o por tema.

## Índice

1. [Qué es Redis y arranque](capitulos/01-que-es-redis-y-arranque.md)
2. [Primeros comandos y tipos de datos](capitulos/02-primeros-comandos-y-tipos.md)
3. [Persistencia y replicación](capitulos/03-persistencia-y-replicacion.md)
4. [Pub/Sub, transacciones y Lua](capitulos/04-pubsub-transacciones-lua.md)
5. [Cluster, buenas prácticas y mini proyectos](capitulos/05-cluster-buenas-practicas-y-proyectos.md)

## Cómo usarlo

Empieza por el capítulo 1 si quieres una introducción completa, o salta directamente al tema que necesites.

Cada capítulo incluye ejemplos prácticos y está escrito para servir como referencia rápida y material de estudio.
